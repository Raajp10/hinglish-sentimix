# Data

SemEval-2020 Task 9 (SentiMix) Hinglish, CC BY 4.0.
Patwa et al., 2020. "SemEval-2020 Task 9: Overview of Sentiment Analysis of Code-Mixed Tweets."
Official release: https://zenodo.org/records/3974927 (Semeval_2020_task9_data.zip)

`raw/` files were taken from the public mirror github.com/singhnivedita/SemEval2020-Task9
(`Original Dataset/{Train,Validation,Test}.txt`, test labels = `Fully Processed Datasets/Ty.txt`).
Test-label distribution (900 neg / 1100 neu / 1000 pos) matches the official test set.
If you can, cross-check `raw/test_labels.csv` against the official `test_labels_hinglish.txt`
from the Zenodo zip.

`processed/` is generated by `python -m src.prepare` (see `processed/stats.json`).
`normalization_dict.json` is generated by `python -m src.normalize`.
